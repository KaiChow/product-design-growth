# 90 次课程地图

## 结构与边界

- Session 01–84：12 周 ×（6 天新课 + 1 天复盘）= 72 个知识点 + 12 次综合复盘。
- Session 85–89：5 次跨领域实战；Session 90：综合结业评估。
- 72 个知识点：产品经理 24、UX 交互 24、UI 视觉 24。每周按 产品→交互→视觉→产品→交互→视觉→复盘 编排。
- 编号指 **第几次学习**，不是自然日。漏学不跳课；同一天重复运行不自动推进。
- 一轮 90 次只是初阶到进阶的训练基础，并不等于达到专家级。
- 单节基础课程默认 15–20 分钟；复盘 20–30 分钟；综合任务 30–45 分钟。时间是建议而非完成保证。

## 周主题速览

| 周次 | 主线 | 本周前三个知识点（示例） |
|---|---|---|
| 01 | 发现问题与建立视觉判断 | 问题与功能请求：先定义问题 / 系统状态可见性 / 视觉层级与阅读顺序 |
| 02 | 认识用户与理解认知 | 用户任务与 JTBD / 识别优于回忆 / 间距、亲密性与分组 |
| 03 | 从证据到结构 | 访谈与行为证据 / 可供性、示能与操作暗示 / 文字与界面对比度 |
| 04 | 形成清晰决策 | 需求优先级与机会成本 / 一致性与遵循惯例 / 语义色与功能色 |
| 05 | 产品边界与常见组件 | MVP 范围与假设 / 表格行操作显隐策略 / 表格的视觉层级 |
| 06 | 查找与组织复杂任务 | 信息架构与对象模型 / 搜索、筛选、排序的边界 / 响应式栅格与断点思维 |
| 07 | 文案、边界与保护 | 文案是产品契约 / 删除与危险操作确认 / 弹窗与抽屉的视觉结构 |
| 08 | 设计取舍与复杂搜索 | 设计取舍与约束表达 / 高级筛选与查询方案 / 留白不是空白 |
| 09 | 用户验证与多步骤流程 | 竞品研究与设计借鉴 / 批量选择与批量操作 / 侧栏、内容区与主次导航 |
| 10 | 协作系统与并发状态 | 产品漏斗与任务完成率 / 角色权限与操作可见性 / 数据可视化与图表选择 |
| 11 | 跨端、一致性与无障碍 | 信息架构验证方法 / 国际化与响应式交互 / 设计 Token 与语义变量 |
| 12 | 验证设计质量与综合能力 | 可用性测试与任务脚本 / 加载、空状态和错误恢复 / 跨页面视觉一致性审计 |

## 机器可执行课表

完整课程定义见 `../data/curriculum.json`。它是选题、顺序、知识点 ID、先修关系的唯一数据源，不要另造课程序号。

### 选题与难度

1. 默认始终按照课表编号向前，不能根据随机兴趣跳过基础；用户明确指定主题可临时教学，但不能悄悄推进主线。
2. 复盘优先考察本周所学，再选 1–2 个到期或低分知识点；没有分数时标记“未评估”，不能判断为已掌握。
3. 提供三个案例领域轮换：普通互联网产品、企业软件/B2B、移动端产品。不要长期只用物流、表格、后台案例。
4. 对第 85–90 次，减少理论讲解，强调设计交付物、标准、争议点和独立判断。
5. 完成 90 次后只总结成果与不足，后续课程需明示新版本，不能自动重置已学记录。
